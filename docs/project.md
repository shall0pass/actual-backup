# Project

This is a backup and tap-to-pay extra program for Actual Budget at actualbudget.org and github.com/actualbudget.

The primary objectives are:
1. an easy to use web interface.
2. OIDC login support
3. Easy management of when to capture backups of the budget.
4. Choices to save historical budgets.
5. Easy management of a tap-to-pay server for use with iOS or android.
